# Cinna Travel

2026 年 9 月 28 日至 10 月 4 日西藏阿里北线自驾行程手册。

这是一个无构建依赖的静态网站，页面、样式与交互均在 `index.html` 中，图片位于 `assets/`。

## 本地预览

```bash
npm run dev
```

打开 <http://127.0.0.1:4173/>。

## 发布 GitHub Pages

```bash
npm run deploy
```

发布脚本会把当前静态站点同步到 `gh-pages` 分支。

线上地址：<https://icelemon233.github.io/cinna-travel/>
